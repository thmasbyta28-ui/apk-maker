PixAnim - pixel animation editor (pure web app: HTML + JS, no server, no build step)
Entry point: index.html  (at the root of this zip)
Files: index.html, manifest.webmanifest, sw.js, icons/icon-192.png, icons/icon-512.png
Works offline. Upload this zip to any "website to APK" builder, or host the folder as a static site.
